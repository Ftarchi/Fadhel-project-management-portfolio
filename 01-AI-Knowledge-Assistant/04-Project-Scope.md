# Project Scope

## In Scope

1. Define the routine HR and IT questions that the MVP can support.
2. Identify and prepare approved knowledge sources for the AI assistant.
3. Define user access and authentication requirements.
4. Establish security and privacy requirements.
5. Define and execute testing requirements.
6. Deploy the MVP to a controlled pilot group of employees.

## Out of Scope

- Finance and Operations questions.
- Customer-facing AI solutions.
- Full HR/IT process automation.
- Enterprise-wide rollout.
